Notes:

- Glow is **three APIs below** the pre-registered >=50 selected-name gate.
  Keep it as a transparent near-threshold pilot or replace it; do not silently
  lower the global threshold.
- The pymatgen pilot revealed and now regression-tests a generic Python bug:
  nested local functions had leaked into `intent`/raw completeness counts.
  API surface and intent now share the AST-backed importable-API denominator.
- The same pilot exposed a second Python parsing bug: class bases were rendered
  as constructor parameters and an inline class docstring could be rendered as
  a return type. Python functions and classes now use AST-derived signatures,
  parameters, and return annotations; the pymatgen pilot was regenerated after
  the fix.
- CDK's full 3,501-name method surface exceeded the 2,000-name ceiling. The
  config now pre-registers a 1,275-name in-process chemistry subset covering
  object models, common algorithms, SMILES/SMARTS, formulas, and descriptors.
- CDK uses the new Java static/README adapter. Execution-grounded
  comprehension still requires a Maven classpath and Java scaffold.
- The CDK pilot caught and now regression-tests Java signature truncation and
  an over-permissive declaration regex. Constructor/method signatures retain
  their parameter lists, return types are structured, and method calls are no
  longer admitted as declarations.
- `gemini-3.2-pro-preview` is unavailable (`404 NOT_FOUND`). The pilots pin
  `google:gemini-3.1-pro-preview`, which the account exposes and which matches
  the earlier RDPro/tslearn/MDAnalysis study model.
- `--limit 10` currently chooses the alphabetically first APIs. It is
  deterministic but not representative; add a seeded/family-stratified pilot
  selector before using pilot quality as evidence.

## Apache Sedona follow-up

Sedona should be run as a close-domain replication, but it is not one of the
three cross-domain additions above. The repository already contains
`experiments/sedona/configs/aideal.yaml`, and the paper plan names Sedona as
the second external case study. A prior live static diagnostic exposed broken
Python docstring and pytest signals; it did not produce a completed generated-
README comparison. Those generic signal bugs are now fixed.

Current screening (2026-09-06): `apache/sedona` is active and unarchived,
Apache-2.0 licensed, primarily Java/Scala/Python, with 2,396 stars and 781
forks. Because it overlaps RDPro/GRAIL in both geospatial domain and Spark
stack, treat it as replication evidence rather than the main diversity claim.
If the study must remain at exactly three new repositories and enforce the
>=50 selected-API gate strictly, Sedona is the natural replacement for Glow;
otherwise retain Glow and add Sedona as a fourth case.
