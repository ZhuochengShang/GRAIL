ROOT CAUSE:
The documentation contains an error in its example: it attempts to save an unfitted model, which raises a `NotFittedError` because `tslearn` estimators must be fitted before their state can be serialized via `to_pickle()`. Additionally, the snippet writer fell back to using standard `pickle.dump()`, which is also incorrect as `from_pickle` expects a specific dictionary format generated by `to_pickle()`.

CORRECT USAGE:
```python
model_path = os.path.join(output_dir, "dummy_model.pkl")
model = TimeSeriesKMeans(n_clusters=2, random_state=123)
model.fit(np.random.rand(10, 5, 1))
model.to_pickle(model_path)

loaded_model = TimeSeriesKMeans.from_pickle(model_path)
```

REQUIRED TYPES & IMPORTS:
`tslearn.clustering.TimeSeriesKMeans`
`numpy`
`os`

DOC MUST SAY:
- The estimator MUST be fitted (e.g., by calling `fit()` on dummy data) before it can be saved with `to_pickle()` and loaded with `from_pickle()`.
- Attempting to save an unfitted model will raise a `NotFittedError`.
- The model MUST be saved using its own `to_pickle(path)` method, not standard `pickle.dump()`, because `from_pickle` expects a specific dictionary representation.
