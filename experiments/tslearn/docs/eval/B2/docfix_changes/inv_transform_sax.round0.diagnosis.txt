ROOT CAUSE:
The documentation incorrectly states that `dataset_sax` should be a float array (`float64` or `float32`). However, the source code uses `dataset_sax` to index into the `breakpoints_middle_` array (`breakpoints_middle_[dataset_sax[i, t, :]]`). Numba strictly requires array indices to be integers, so passing a float array causes a `TypingError` during JIT compilation.

CORRECT USAGE:
```python
import numpy as np
from tslearn.metrics.cysax import inv_transform_sax

# dataset_sax MUST be an integer type for Numba indexing
dataset_sax = np.array([[[0], [1], [2]]], dtype=np.int64)
breakpoints_middle = np.array([-0.5, 0.0, 0.5], dtype=np.float64)
original_size = 6

dataset_out = inv_transform_sax(dataset_sax, breakpoints_middle, original_size)

assert dataset_out.shape == (1, 6, 1)
assert np.allclose(dataset_out[0, :, 0], [-0.5, -0.5, 0.0, 0.0, 0.5, 0.5])
```
